# cavernous

Minimal holding page for cavernous.co.uk.

- Black full-viewport background
- Centred CAVERNOUS eclipse symbol and lowercase wordmark
- Two mathematically perfect, equal-radius circles (r=240, centre separation=100 SVG units)
- Full circle outlines and solid white left crescent
- Responsive, static, no external dependencies

No AI-agent information layer is published in this version.

Open `index.html` in a browser to preview locally.
